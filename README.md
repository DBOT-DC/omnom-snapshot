# OMNOM Token Holder Snapshots

Weekly snapshots of $OMNOM token holders on Dogechain.

## Contents

### Core Files
- `omnom-snapshot-FINAL.json` — Pre-announcement baseline snapshot (June 7, 2026, Block 59,922,100)
- `omnom-snapshot-pre-announcement.csv` — CSV version of pre-announcement snapshot
- `HASHES.json` — SHA-256 hashes for integrity verification

### Weekly Snapshots (`weekly/`)
- `weekly-YYYY-MM-DD.csv` — All holders at snapshot time
- `weekly-YYYY-MM-DD.json` — Full JSON with metadata + all holders

### Master Lists (from bot workspace)
- `omnom-snapshot-ever-held.csv` — Union of ALL snapshots (every address that ever held OMNOM)
- `omnom-snapshot-latest.csv` — Most recent snapshot (currently holds)
